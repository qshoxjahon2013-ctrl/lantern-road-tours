# Lantern Road Tours: sample website

A one-page, bilingual (English / Uzbek), heavily animated website for a **fictional** tour company in Khiva, Uzbekistan.
Plain HTML, CSS and JavaScript with no libraries, so it can be hosted for free on GitHub Pages or Netlify.

**Animations**
- Intro: a lantern draws itself and lights up, then the city gates slide open
- Hero: a canvas night sky with floating sky lanterns, twinkling and shooting stars; click the sky to release more lanterns
- Khiva skyline (original SVG) builds itself: minarets grow, the wall rises, the moon glows, tiles shimmer, and the layers follow the mouse (parallax)
- Headings rise word by word; numbers and prices count up
- A Silk Road map that draws the route Khiva → Bukhara → Samarkand while you scroll, with a travelling lantern and city stops
- 3D tilt cards with light glare, self-drawing line icons, a sun that moves across the 3-day itinerary, a progress line through the booking steps
- Moving marquee of place names, reading progress bar, custom cursor, magnetic buttons, ripples, flying lanterns when the form is sent
- Respects "reduce motion" settings: everything becomes calm and static

The company, prices and figures are fictional. Facts about Khiva, Bukhara and Samarkand are real.
